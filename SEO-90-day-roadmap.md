# Veda Junior SEO — 90-Day Roadmap

**Start:** 30 September 2026  
**Principle:** grow qualified organic visibility with accurate current information, preserved historical authority and no visual redesign.

## NOW — first 48 hours

1. In Google Search Console inspect and request indexing once for the four canonical URLs: homepage, child school, professional ballet, gallery.
2. Confirm Google-selected canonical is the non-www HTTPS URL for each.
3. Add the canonical domain to every controllable external profile: Facebook, Instagram bio, Google Business Profile, KartaSofia, Business.bg and Golden Pages if claimable.
4. Save baseline Search Console exports: Queries, Pages, Countries, Devices for last 28 days and previous 28 days.
5. Run PageSpeed Insights for homepage on mobile and desktop; record LCP, CLS, INP and exact LCP element before any performance change.
6. Check Google Business Profile: primary category, website, phone, hours, service descriptions and current photos.

## 7 days

1. Confirm sitemap processed and no coverage/canonical warning for the four URLs.
2. In Search Console, create a watchlist for historic routes and www results; do not add redirects unless a new exact broken legacy URL is evidenced.
3. Ask for one or two fresh, verified photos from a current class or performance for Google Business Profile and official social channels.
4. Prepare a factual list of current entry ages, beginner availability, current halls and enquiry process. Do not publish schedule or prices until verified.
5. Send no outreach yet; first establish which high-relevance mentions have a link and which have only text.

## 14 days

1. Compare 28-day Search Console data with previous period (not day-to-day fluctuations).
2. Identify query/page pairs with meaningful impressions, average position 5–30 and weak CTR; select maximum two changes for the next sprint.
3. Identify position 1–5 results with poor CTR; test a new title/description only when the user intent is clearly better served.
4. Claim or correct one genuine local listing at a time. Use the canonical website and only business details confirmed by Veda Junior.
5. Begin ethical review flow after a positive real interaction; see below.

## 30 days

1. Decide whether a factual child-school paragraph can cover beginner/age intent naturally. It requires owner-verified current information.
2. Review which canonical page gained impressions after migration and whether legacy results are declining.
3. Run a live image/gallery network audit in browser; fix only measured broken/oversized/loading issues.
4. Approach only 2–3 high-relevance cultural/media/event mentions for a canonical link correction or future event-page link.
5. Publish an official, factual Google Business Profile update only if it is genuinely current (new term, confirmed event, confirmed class availability).

## 60 days

1. Re-run competitor review for the query clusters that have actual Search Console impressions.
2. Audit NAP consistency across controllable profiles; do not create duplicate Business Profiles for halls.
3. Review review growth: number, recency, response rate and recurring parent questions. Never request only positive reviews.
4. If Google Images data shows opportunity, prepare a safe image asset plan based on measured dimensions and current upload workflow.
5. Reassess schema only for facts that are externally confirmed and present on the visible site.

## 90 days

1. Compare 90-day organic trend, canonical page impressions, CTR and average position against the pre-recovery baseline.
2. Decide whether one new information resource is justified. It must serve a distinct, evidenced query intent that current pages cannot serve without cannibalisation.
3. Refresh only genuinely stale current information; retain historic achievements as historical.
4. Review backlink reclamation results and repeat only with high-quality relevant publishers.

## Ethical Google review flow

**When:** after a parent has had a positive real experience—e.g. after a first month, a performance, or a resolved enquiry. Ask all eligible parents neutrally, not only those likely to leave five stars.

**QR idea:** a small card at events/registration desk with one QR code to the single primary Veda Junior Google review link. Do not offer discounts, gifts or conditions.

**Short message:**

> Здравейте! Благодарим, че сте част от Veda Junior. Ако имате минутка, ще ни помогне много да споделите честното си мнение в Google: [линк]. Това помага на други родители да ни открият. Благодарим!

**One follow-up (only once, 7–10 days later):**

> Само напомняне, ако все още не сте имали възможност: вашето честно мнение за Veda Junior би ни помогнало много. [линк] Благодарим!

## Google Business Profile checklist

- One primary profile only, unless a separate eligible staffed business location exists and is approved by Google rules.
- Primary category must match the real offer; add secondary categories only if genuinely accurate.
- Use canonical website URL and current primary phone.
- Describe services factually: детска школа по танци, модерен балет, модерни/съвременни танци where accurate.
- Add current, well-lit photos with clear ownership/permission.
- Answer recurring questions factually; never write fictitious Q&A.
- Reply politely to every review without sharing child personal information.

## KPI dashboard

| KPI | Primary source | Decision rule |
|---|---|---|
| Canonical indexed pages | Search Console Pages / URL Inspection | All four canonical pages should be indexed and self-canonical. |
| Organic impressions | Search Console, 28-day comparison | Use trend, not a single day. |
| Queries in positions 5–30 | Search Console Queries | Prioritise when impressions are meaningful and intent is relevant. |
| CTR | Search Console Query + Page | Test snippets only when low CTR persists. |
| Legacy URL consolidation | Search Console Pages + site search | Expect gradual decline; do not remove redirects. |
| Review count / recency | Google Business Profile | Seek authentic, steady feedback. |
| CWV | Search Console + PageSpeed | Change code only after a measured root cause. |

## Stop conditions

- Do not add a new page without distinct, proven user intent.
- Do not change a verified redirect, current business fact or gallery image naming without evidence.
- Do not change copy solely to repeat a keyword.
- Do not use legacy addresses, old hours or historic events as current local information.
